# Couchwave releases

**Couchwave** is a media player app for Fire TV and Android TV. It is a **personal project**: made by one person
for their own use and shared as-is. It is not a company, not a commercial product, and not an official app of
anything.

This repository only hosts the installable files of the app. It holds no source code, no content and no accounts.
It is the place the app checks for new versions (`latest.json`) and downloads them from.
